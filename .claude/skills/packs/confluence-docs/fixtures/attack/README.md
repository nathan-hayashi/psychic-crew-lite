# fixtures/attack — adversarial document fixtures (S3a)

TRACKED on purpose: these are the inputs the pack's untrusted-input contract is tested against, and
a test you cannot read is not evidence. Every string here is **generic and invented**. No real
document content, no real credential, no real host — a fixture that carried either would put the
thing it defends against into a public repo.

Each file is a document a reviewer might legitimately be handed, carrying one attack. The live drill
in `docs/security/redteam-1.md` records what the pack did with each.
